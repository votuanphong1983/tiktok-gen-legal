TiktokGen Privacy Policy

Last updated: October 9, 2026

This Privacy Policy explains how TiktokGen ("the app"), a personal tool operated by Vo Tuan Phong, accesses, uses, stores and shares data when you sign in with Google.

1. Data we access

  • Google account authorization: an OAuth access token and refresh token issued by Google for the scopes https://www.googleapis.com/auth/youtube.upload and https://www.googleapis.com/auth/youtube.
  • YouTube channel information: the channel name/ID of the authorized account, used to confirm videos are uploaded to the correct channel, and the channel's playlists, used to add uploaded videos to the right playlist.

The app does not access your email contents, contacts, files, payment information, or any data beyond the scopes listed above.

2. How we use the data

  • To upload videos created by the app to the authorized YouTube channel, set their title, description and tags, and add them to a playlist.
  • Tokens are used solely to call the YouTube Data API on behalf of the channel owner, and only when the owner explicitly chooses to publish a video.

3. Storage and security

OAuth tokens are stored only in a local configuration file on the owner's own computer. They are never sent to any server operated by the app, because the app has no server. Data is not sold, rented or used for advertising.

4. Sharing

We do not share Google user data with any third party. Data is transmitted only to Google/YouTube APIs as needed to perform the upload.

5. Google API Services User Data Policy

TiktokGen's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

6. Retention and deletion

Tokens are kept until the owner deletes them from the local configuration file or revokes access. You can revoke the app's access at any time at https://myaccount.google.com/permissions; revoked tokens stop working immediately. To request deletion of any data, email the contact below.

7. Children

The app is not directed to children and does not knowingly collect data from children.

8. Changes

Changes to this policy will be posted on this page with an updated date.
